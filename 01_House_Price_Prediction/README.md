# House Price Prediction

## CODTECH AI Internship - Task 4

A beginner-friendly machine learning application that predicts an estimated house price from property features.

### Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

### ML Algorithm
Linear Regression

### Features
- Area in square feet
- Number of bedrooms
- Number of bathrooms
- House age
- Location score
- Parking spaces

### How to run
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Workflow
Dataset → Train/Test Split → Linear Regression → Evaluation → Prediction

### Important
The dataset is a synthetic educational dataset created for this internship project. Predictions are demonstrations and are not real property valuations.
