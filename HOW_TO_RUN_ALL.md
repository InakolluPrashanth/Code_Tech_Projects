# How to Run the CODTECH AI Projects

Open a terminal inside any project folder.

Example:

```bash
cd 01_House_Price_Prediction
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Then:
```bash
pip install -r requirements.txt
streamlit run app.py
```

Repeat for each project.

The same pattern applies to all four projects:
1. Open project folder
2. Create/activate virtual environment
3. Install requirements
4. Run `streamlit run app.py`
5. Test
6. Take screenshots
7. Push to GitHub
8. Submit through CODTECH

Important: read the exact submission fields in the CODTECH portal before uploading.
