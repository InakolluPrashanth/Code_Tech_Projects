# Email Spam Classifier

## CODTECH AI Internship - Task 3

A beginner-friendly NLP project that classifies messages as spam or not spam.

### Technologies
- Python
- Pandas
- Scikit-learn
- Streamlit

### ML Concepts
- Text preprocessing
- TF-IDF
- Multinomial Naive Bayes
- Train/test split
- Classification accuracy

### How to run
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Workflow
Text Dataset → TF-IDF → Naive Bayes → Prediction

### Note
This is an educational classifier trained on a small demonstration dataset. It should not be used as a real email-security system.
