# Handwritten Digit Recognition

## CODTECH AI Internship - Task 2

A basic computer-vision/machine-learning application that recognizes handwritten digits from the scikit-learn digits dataset.

### Technologies
- Python
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

### ML Algorithm
Logistic Regression

### Dataset
Scikit-learn's built-in handwritten digits dataset. It contains 8×8 grayscale images of digits from 0 to 9.

### How to run
```bash
pip install -r requirements.txt
streamlit run app.py
```

### Workflow
Digit Images → Train/Test Split → Logistic Regression → Prediction → Accuracy

### Note
This beginner implementation uses the built-in 8×8 digits dataset rather than a full 28×28 MNIST application.
