# CODTECH AI Internship - Submission Checklist

You have four selected projects:

1. Movie Recommendation Engine
2. Handwritten Digit Recognition
3. Email Spam Classifier
4. House Price Prediction

## For EACH project

### 1. Build
- Keep the project folder structure unchanged unless you know what you are changing.
- Install the packages from requirements.txt.
- Run the app locally.
- Test several inputs.

### 2. GitHub
Recommended: one separate repository for each project, unless CODTECH explicitly says otherwise.

Suggested repository names:
- codtech-movie-recommendation
- codtech-digit-recognition
- codtech-spam-classifier
- codtech-house-price-prediction

Push:
- app.py
- data/
- requirements.txt
- README.md
- screenshots/

Do NOT upload:
- .venv/
- passwords
- API keys
- secret credentials

### 3. README
Each README should contain:
- Project title
- Internship/task number
- Objective
- Technologies
- Algorithm
- Dataset
- Features
- How to install
- How to run
- Workflow
- Example output
- Limitations

### 4. Screenshots
Take at least:
- Main application screen
- Input screen
- Successful output/prediction
- Model/result screen if applicable

Put them in a `screenshots/` folder.

### 5. Demonstration video
Show:
1. Project title
2. Brief objective
3. Application running
4. Input
5. Output
6. Short explanation of the algorithm
7. GitHub repository

Keep the video clear and focused.

### 6. CODTECH submission
Use the SUBMIT button for the matching task in your dashboard and follow the exact fields shown there. Do not invent a submission format if the portal asks for something different.

## Recommended completion order
1. House Price Prediction
2. Email Spam Classifier
3. Movie Recommendation Engine
4. Handwritten Digit Recognition
